# Chattree Developer Tools

This directory is designated for official developer tools, local utility scripts, and development CLI extensions.

---

## Purpose & Scope

The tools housed here assist developers and maintainers with:
- Local manifest validation and syntax checking.
- Plugin packaging, bundling, and asset integrity verification.
- Local sandbox harness and developer debugging utilities.

---

> **Note:** Official developer tools will be added as platform toolchains and SDK components are published.
