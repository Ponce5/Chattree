# Official Plugin Starter Template

This directory is reserved for the official Chattree plugin starter template and scaffolding boilerplate.

---

## Purpose

The forthcoming template in this directory will provide developers with a turnkey foundation to create new Chattree plugins conforming to best practices:

- Pre-configured manifest definition.
- Typed SDK bindings and lifecycle handlers.
- Standard build, packaging, and linting configurations.
- Unit and integration testing scaffolding.

---

> **Note:** The official plugin template will be added once plugin SDK packaging and tooling are officially released.
