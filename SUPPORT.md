# Getting Support for Chattree

Thank you for being part of the Chattree developer ecosystem. This document provides guidance on how to find answers, request assistance, and report issues.

---

## Which Channel to Use

### 1. Bug Reports
- If you find a bug in the documentation, official plugins, schemas, or developer tools, please submit an issue using the appropriate template once issue tracking is enabled.
- Provide minimal reproduction steps, expected behavior, actual behavior, and relevant environment details.

### 2. Feature Requests & Proposals
- Have an idea for improving an official plugin or a new developer tool? Propose your feature via repository discussions or feature request issue templates once published.

### 3. General Questions & Discussions
- For questions about developing plugins, understanding schemas, or architectural design, please use the official community discussion forums once active.

### 4. Security Vulnerabilities
- For security-sensitive issues, do not use public issue trackers. Follow the instructions in [SECURITY.md](./SECURITY.md).
