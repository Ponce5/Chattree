# Chattree Calendar Plugin (v1.8.0)

Official on-device Calendar integration for Chattree with multilingual AI orchestration and declarative Flutter UI cards.

## Features

- **Multilingual Natural Language:** Schedule, list, update, and delete events in any language via `/calendar <request>`. All user-facing summaries, card headers, labels, and usage instructions are dynamically generated by the AI in your active language (`ai.context`).
- **Declarative Flutter UI Cards (`ui.components`):**
  - Bare `/calendar` fetches your device calendar events and renders an interactive Flutter list card with dates, times, descriptions, and a quick refresh action.
  - Scheduling, updating, or deleting an event renders a structured Flutter confirmation card displaying the event title, date, time range, and description.
- **First-Run Reliability:** Automatically resolves a writable device calendar via `calendar.calendars` before creation, normalizes camelCase Host API parameters, handles OS permission prompt timing cleanly, and performs an automatic retry on transient sync failures.
- **Direct Pipe Syntax:** `/calendar <title> | <YYYY-MM-DDTHH:mm:ss> [| <YYYY-MM-DDTHH:mm:ss>] [| <description>]`.

## Required Capabilities

| Capability | Purpose |
|---|---|
| `calendar.read` | Inspect calendars and retrieve upcoming events. |
| `calendar.create` | Schedule new events on the device calendar. |
| `calendar.update` | Modify existing events by `eventId` and `calendarId`. |
| `calendar.delete` | Delete events by `eventId` and `calendarId`. |
| `ui.components` | Render interactive Flutter UI cards in chat. |
| `ai.context` | Generate multilingual responses, card labels, and contextual help. |

## Build & Validate

```bash
node scripts/build-calendar-wat.mjs
node tools/validate-plugin.mjs plugins/official/calendar/
node tools/package-plugin.mjs plugins/official/calendar/
```
